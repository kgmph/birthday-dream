# Birthday Dream — fixed edition

## IMPORTANT: How to open the site
1. Right-click the ZIP and select **Extract All**.
2. Open the extracted **Chase_Birthday_Edit_Sandton** folder.
3. Double-click `index.html` **inside that folder**. Do not open it from inside the ZIP.
4. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder together.

For GitHub Pages, upload **the contents of this folder** to your repository root. Under Settings → Pages, deploy from the `main` branch and `/ (root)`.

The site uses your supplied photos and wishlist prices. Check offers and availability before purchasing. The background music button needs an audio file named `assets/birthday-music.mp3` that you have permission to publish.

## Add your music
Upload your MP3 to this chat, or put a licensed MP3 inside the `assets` folder and rename it exactly `birthday-music.mp3`. Keep the file next to the other assets, not next to index.html. The MUSIC OFF button toggles playback after a click because browsers block autoplay. If deploying to GitHub, commit the MP3 as well. Only publish music you have permission to share.


## Music and publication rights
The uploaded Burna Boy track is included for LOCAL PREVIEW ONLY. You should not publish or distribute it through GitHub Pages unless you have the necessary rights or permission. Before making the repository public, replace `assets/birthday-music.mp3` with music licensed for website use (or remove it and the music controls). Music starts only when visitors press one of the clearly labeled PLAY MUSIC buttons, because browsers block autoplay.


## Publishing this version
The navigation has been spaced into separate brand, menu and music areas, including a two-row mobile layout. This GitHub upload package omits the commercial soundtrack. To use music publicly, replace `assets/birthday-music.mp3` with a track you have the rights to publish.

1. Create a new **public** GitHub repository named `birthday-dream`.
2. Select **Add file → Upload files**, and upload the **contents of this folder** (including `assets`, `styles.css`, `script.js`, and `index.html`) to the root of your repo. You can drag the entire contents into the upload page.
3. Commit the upload to `main`. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Select `main` and `/(root)`; save.
4. Visit `https://YOUR-USERNAME.github.io/birthday-dream/` once deployment finishes.
5. If you add an authorized MP3 later, upload it to `assets/birthday-music.mp3` and commit the change.

Note: GitHub Pages publishes files publicly. Product prices and flight options are user-provided and may change. Air Botswana branding is a design request, not verified flight availability.
